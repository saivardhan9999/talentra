Try the blocking rule
  1. As the Recruiter, open Candidate search and search for the candidate's name: they appear.
  2. Switch to the Candidate and block the recruiter's company below.
  3. Switch back to the Recruiter and search again: the profile is gone. The other company's recruiter still sees it.
  4. Unblock to restore it.
